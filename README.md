# GREEN-API Мессенджер

Простой веб-интерфейс для отправки и получения сообщений через GREEN-API 

Стек: **React + TypeScript + CSS Modules + Vite**

## Запуск проекта

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev

# 3. Открыть в браузере
http://localhost:5173
